# Voorspel herseninfarct – Portfolio-opdracht 1 Machine Learning (2026-27)

Teamnotebook voor de Kaggle-competitie
[Predicting stroke 2026-27](https://www.kaggle.com/competitions/predicting-stroke-2026-27).
We voorspellen met machine learning of een patiënt een herseninfarct (stroke)
krijgt. De modellen worden beoordeeld met de F1-score.
